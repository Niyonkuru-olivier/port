# Logo Placement

## Where to place logo.png

Place your `logo.png` file in this exact location:

```
StoreMIS/
├── public/
    └── assets/
        └── logo.png  <-- PUT YOUR LOGO HERE
```

## Full Path

The logo file should be located at:
- **Windows**: `C:\Users\Olivier\Music\StoreMIS\public\assets\logo.png`
- **Full relative path**: `public/assets/logo.png`

## Logo Requirements

- **Format**: PNG
- **Recommended size**: 200x200 pixels or similar square dimensions
- **Background**: Transparent or white
- **File name**: Must be exactly `logo.png`

## Current Status

Your logo will appear in the top-left corner of all generated reports (Inventory and Asset reports).

The logo is included automatically if the file exists at the specified location.
